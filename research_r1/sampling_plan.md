# Luxury Handbag R1 采样计划（第 1 步）

状态：`draft / planning artifact`。本文件定义下一轮取样如何发生；其中的目标数量和候选家族不是已经完成的采集结果，不能当作在售组合覆盖率。

## 1. 研究问题与边界

本轮要回答的是：在法国与美国同一当前快照中，Chanel 的价格梯、Classic 锚点和进入/核心层之间的间隔，在补足产品用途、材质和常规/特殊款标记后是否仍然成立；并且能否找到至少一个属性可核实、可重算的跨品牌配对。

核心范围为 Chanel、Hermès、Louis Vuitton、Dior 的法国（EUR）和美国（USD）官方当前标价。当前基线快照固定为 `current_2026-08-15`。中国市场、消费者访谈、转售和销量/利润数据属于后续扩展，不能在核心门槛尚未满足时混入主结论。

## 2. 采样框架

采样框的逻辑键是：

`brand × market × product_family × use_tag × size_group × material_group × regular_special × snapshot × batch`

一条合格采样单位必须有可追溯的品牌、市场、币种、观察日期、产品家族或型号、官方参考号（若页面提供）、用途标签、尺寸组、材质组、常规/特殊（`regular_special`）状态和价格状态。颜色变体在原始层保留，但在去变体敏感性中只作为同一 `devariant_group` 的成员，不单独获得家族权重。

“合格”描述数据行的身份和证据完整度，不描述产品是否真的可买，也不把 `price_upon_request` 或无法解析的价格估成数值。

### 候选家族与用途

Chanel 的定向补充候选家族为：`Classic 11.12`、`Mini`、`2.55`、`Boy`、`19`、`22`、`25`、`Shopping/Bowling`、`WOC`。这些名称是待验证的候选框；页面当前可见性、参考号、尺寸、材质和常规/特殊状态都必须重新核实。WOC 单独作为小皮具/小尺寸敏感性组，不自动并入手袋主分母。

四品牌的用途标签先采用可复核的宽口径：`flap`、`shoulder`、`crossbody`、`tote/shopper`、`top-handle`、`evening/mini`、`small-leather-goods`。在 `product_master` 建立前，不能凭家族名称把一个品牌的标签映射到另一个品牌的“同款”。

### 计划目标（[A] 规划选择）

- 每个品牌 × 市场先建立一个候选框，再按用途和家族展开；不把现有 20/21 条观察误读为完整目标数。
- 对每个进入核心比较的家族 × 市场，优先争取 3–5 个合格配置，覆盖至少一个常规皮革和一个非皮革/帆布或其他明确材质分支（若品牌页面实际存在）。这只是试采目标，不是必须“填满”的配额。
- 先固定同一市场、同一观察窗口和同一宽口径用途，再尝试尺寸组和材质组匹配；不能为了达到 N 值放宽属性约束。
- 一轮试采后冻结候选框。关键缺口最多进行两次有记录的重试；仍无法得到可核实价格时，保留为 `attempted_unresolved`、`attempted_por` 或 `attempted_sold_out`，不改成零值。
- 本轮计划最多新增 60 条候选行；超出上限必须先更新计划和可行性矩阵，不能静默扩大范围。

## 3. 状态字典

| 状态 | 含义 | 是否进入价格分布 |
|---|---|---|
| `targeted` | 候选框中计划核实，尚未尝试 | 否 |
| `attempted_numeric` | 已尝试且取得可追溯正数价格 | 是 |
| `attempted_por` | 页面明确询价/联系门店 | 否 |
| `attempted_unresolved` | 页面或来源已尝试，但身份或价格无法核实 | 否 |
| `attempted_sold_out` | 识别到产品，但当前页面显示售罄/不可售 | 否 |
| `excluded` | 不符合当前研究定义（例如特殊款、WOC 主样本、重复变体） | 否 |
| `unknown` | 尚未判断，不能当作缺失为零 | 否 |

## 4. 试采、正式样本与停止规则

试采的目的，是检验用途、材质、常规/特殊字段和参考号能否从官方页面稳定取得；试采结果本身不升级为核心结论。只有在身份、日期和价格状态可复核，并且至少存在一个可解释的跨品牌配对单元时，才可进入正式核心样本。

停止条件为：候选家族已完成一次尝试并记录结果；关键缺口已重试不超过两次；或已达到新增候选行上限。任何停止都要在 `feasibility_matrix.csv` 和 `unresolved.csv` 中留下原因。不得以“已有足够 N”替代覆盖机制说明。

## 5. 计划输出与指标

下一步应生成 `product_master`、`sku_mapping` 和补充观察，并重新计算以下指标：

1. **数值价格覆盖率**：`attempted_numeric / accepted attempted rows`，按品牌、市场、家族报告；POR、未解析、售罄分开。
2. **采样框覆盖率**：已尝试的合格候选单位 / 计划候选单位；这不是官网全量覆盖率。
3. **去变体组数与家庭权重**：颜色变体合并后，报告每个家族有多少独立参考组；主比较按家族等权，不按抓取行数等权。
4. **字段完整度**：用途、尺寸、材质、常规/特殊、参考号各自的非空率，并标出推断字段。
5. **匹配准备度**：至少有多少品牌 × 市场 × 用途 × 尺寸组 × 材质组单元达到可核实身份；未达到者只能作 `reference-only` 或 `incomparable`。
6. **日期对齐度**：当前比较是否来自同一快照；历史比较只使用共同观察年份，不对缺失年份插值。

## 6. 偏差与可推断范围

官方页面可见性、地区库存、登录/反爬、询价机制和特殊款发布节奏会造成选择性缺失。Chanel 的 POR 和 Dior 美国未解析价格不能与普通数值缺失视为同一种机制；Hermès 当前基线没有同口径 signature flag，也不能把它当作“无标识”。

在本计划完成前，结果最多支持公开标价样本的架构和候选竞争位置。不能推出全量商品组合、销售额、需求、支付意愿、利润、品牌资产因果、最优价格或管理层意图。

## 7. 后续顺序（不在本步执行）

1. 按 `feasibility_matrix.csv` 选择一次试采；
2. 建立 `product_master` 与 `sku_mapping`，并完成 Chanel 定向补充；
3. 仅对属性完整的行建立 `comparable_pairs`，再决定哪些单元可进主文；
4. 在核心门槛满足后，再考虑中国区域、访谈或转售扩展。
