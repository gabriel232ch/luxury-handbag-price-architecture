# Wave 5 core hobo candidate search — US, 2026-09-09

## Scope

This search attempted to add one core-size-known Chanel hobo family and one core-size-known Louis Vuitton hobo family after the 2026-09-08 Wave 4 audit. Because the current collection date is 2026-09-09, these observations are kept as a new date and are not merged into the 2026-09-08 panel.

## Findings

- **Chanel AS5311-B20304-94305, CHANEL 25 Medium Handbag:** the official US detail page exposes an explicit Medium label, price USD 7,000, grained calfskin and numeric dimensions 15.7 x 11.8 x 5.9 in (39.9 x 30.0 x 15.0 cm). It is a useful size configuration, but it belongs to the already represented CHANEL 25 family (AS5293), so it does not add a new independent family. The detail page shows Contact Us/appointment and no named regular/season marker.
- **Chanel AS3261-B19059-94305, CHANEL 22 Handbag:** the official US detail page exposes price USD 6,400, shiny calfskin and numeric dimensions 14.2 x 16.5 x 3.1 in (36.1 x 41.9 x 7.9 cm), and the current Hobo category places the family in the hobo route. The product title has no named size label, and the CHANEL 22 family is already represented by AS3260; it remains isolated as unknown-size and non-independent-family evidence.
- **Louis Vuitton M47180, CarryAll PM:** the official US detail page exposes an explicit PM label, price USD 3,450, a body-friendly hobo description, leather composition and numeric dimensions 11.6 x 9.4 x 4.7 in (29.5 x 23.9 x 11.9 cm). It is a new CarryAll family and is a valid core candidate for a future same-date rebuild. The page says “edited this season” but does not identify a named collection; `regular_special=not_disclosed` is retained. The page exposes Contact an Advisor rather than a clear online stock control, so availability is `contact_only`.

## Result

This search found one new Louis Vuitton core candidate, but no new independent Chanel hobo family that simultaneously has a named size and a non-explicit-season status. The Chanel 25 Medium row improves size coverage but cannot be counted as a new family; the Chanel 22 standard row lacks a named size. No 2026-09-09 row is promoted to the 2026-09-08 panel.
