# CHANEL 25 客户选择验证表

本表用于检验日常用包需求如何参与选择，以及购买是否增加当期 Chanel 支出。它把已观察到的首购、共同持有、退换和未选购案例转成可以访谈和记录的问题。当前版本为研究工具，尚未采集新受访者回答。

## 先确定这次讨论的选择

主要窗口为 2025 年发生的购买或实际选购经历。若讨论的是 2026 年或时间不明的经历，另记期间，后续分析时分别处理。回溯访谈须记录访谈日期、事件日期及日期依据；只记得月份就保留月份，帖子发布时间不能代替购买时间。

每条记录对应一位受访者的一次选择经历。退货、换尺寸和再次购买以关联事件记录，避免把同一笔预算当成多次新增购买。受访者可能是付款人、收礼人或使用者，须明确谁决定预算、谁选择款式。

开始前说明研究用途，取得记录与匿名引用许可。受访者可以跳过金额问题；如自愿提供凭证，只记录核验结果和必要的商品、日期、渠道信息，不收集姓名、地址或支付信息。记录模板使用研究编号。

可纳入四种经历：购入并使用、购入后退换、认真比较后选择其他产品或暂缓购买，以及仍在计划中。门店见闻可补充供货信息，单独记录。招募时同时寻找首购和既有客户，并保留不同结果的案例；这里的目的性选取用于检验解释，不能生成市场占比。

## 访谈问题与追问

先让受访者讲述经过，再追问缺失信息。表中的示例帮助研究者记录，初次提问时不要逐项读成答案选项。

| 顺序 | 向受访者提问 | 需要记录或追问什么 |
|---|---|---|
| Q1 | 请从开始考虑买包讲起，到现在发生了什么？ | 开始考虑、比较、试用、付款、退换、最终保留的顺序；区分计划与已完成行为 |
| Q2 | 这次您希望这个包解决什么需要？之前怎么处理这个需要？ | 工作、通勤、旅行或其他实际场景；原来使用的包与尚未满足的需要。用途由受访者先说 |
| Q3 | 当时还认真考虑过哪些选择？哪一个最接近最后的决定？ | Chanel 其他款、其他品牌、二手、继续用现有包或暂缓；区分认真备选与仅知道的款式 |
| Q4 | 如果当时买不到这款 CHANEL 25，您接下来会怎么做？ | 追问准备买什么、何时买、在哪里买，以及当时已有的搜索、试背、预约或预算安排；允许“想不起来” |
| Q5 | 买这只包之前，您对这笔钱有什么安排？后来具体调整了哪些购买或支出？ | 是否用新增预算、替代其他 Chanel 购买、转自其他品牌、调整其他品类、推迟原本的购买；可以有多种调整 |
| Q6 | 在这次选择前，您买过或拥有过哪些 Chanel 产品？ | 首次买手袋与首次买任何 Chanel 分开；付款、赠礼、二手拥有分开；询问当时原本计划的其他 Chanel 支出 |
| Q7 | 您最早怎样知道这款包？后来哪些接触影响了选择？ | 由受访者先回忆，再追问广告、社交内容、朋友、销售人员、门店试背等接触。逐项记录发生在付款之前还是之后 |
| Q8 | 从想买到买到，供货、尺寸、材质、价格或购买地点怎样影响了决定？ | 最初目标版本与最终版本；是否因旅行、排队或缺货改变购买；若价格影响选择，追问实际比较对象与当时金额 |
| Q9 | 现在这只包是什么状态？实际使用和买前想象有哪些差别？ | 保留、退货、换款、转售或未成交；换款关联到原事件。常用程度只记录受访者描述，不换算成销售贡献 |
| Q10 | 回看这次决定，还有什么比我们刚才谈到的因素更重要？哪部分您现在不太确定？ | 保留相反解释、遗漏因素和记忆不确定性；不要替受访者整理成单一原因 |

受访者未选 CHANEL 25 时，Q4 改为：“如果当时没有您最终选择的产品，您下一步会怎么做？”同时追问 CHANEL 25 在备选中的位置和放弃原因。仍在计划中的案例记录当前备选、预算安排与决策条件，在完成购买后再补结果。

金额不是必答项。需要记录时，采用受访者当时使用的币种，分别记原预算、实际支付及退货退款；无法确定则记 `unknown`。一次性支出与全年预算分开，不把不同货币或不同年份直接相减。

## 如何判读回答

首购身份、预算变化、购买结果和广告接触是不同维度。编码时各自记录，再检查它们是否支持同一条解释。

| 字段 | 可用代码 | 使用规则 |
|---|---|---|
| `outcome` | `kept / returned / exchanged / resold / bought_alternative / deferred / planned / unknown` | 以最后已知结果为准；拥有或曾购买并不自动等于最终保留 |
| `channel` | `brand_direct / authorized_retail / resale / gift / unknown` | 二手购买只支持二手选择行为；礼物需追问付款渠道，不能按收礼人体验推品牌收入 |
| `prior_brand_relationship` | `first_brand_purchase / first_handbag_purchase / existing_brand_customer / owned_only / unknown` | 只买过香水的人可能首次买手袋，却已是品牌客户；持有与亲自购买分开 |
| `next_best_choice` | `other_chanel / other_brand / resale / existing_bag / defer / mixed / unknown` | 记录受访者的备选描述。已购买其他款与“没有新品会买什么”的假设回答分开 |
| `budget_effect` | `extra_brand_spend_reported / within_brand_shift_reported / brand_switch_reported / timing_shift_reported / mixed / unknown` | 分类需有 Q4–Q6 的明确回答。外部品牌预算转入 Chanel 可能增加品牌支出，同时保持总手袋预算不变 |
| `event_period` | 日期／月份／年份／`unknown` | 另记日期精度与依据。购买提前到当年，与新增长期需求具有不同含义 |
| `ad_order` | `before_purchase / after_purchase / no_recalled_exposure / mixed / unknown` | 先后成立只说明广告可能参与购买；没有记起广告不等于未接触 |
| `evidence_basis` | `self_report / public_account / voluntary_document / linked_followup` | 留下出处和定位。凭证可以核对事件，不能核验“没有新品时会怎样”的回答 |

同一条证据可支持多个代码，例如日常用途与因尺寸不合而退货可以同时出现。预算发生多种调整时，记 `mixed` 并解释，不强行选主因。没有回答的字段统一记 `unknown`；不适用的字段记 `not_applicable`；拒答记 `declined`。

研究者写下原话或定位、代码依据、相反证据及未解决问题，避免只保留概括。另一个读者应能从记录看出为什么这样编码；若解释有分歧，保留分歧与待追问项。

## 从记录走向研究判断

若明确发生品牌渠道购买、最终保留，并自述增加了当期 Chanel 支出，可记录为“自述支持品牌支出增量”。仍需检查是否替代其他 Chanel 品类、是否只是把后续购买提前，以及付款与退换是否落在研究窗口内。这种回答提高机制可信度，不能当作已识别的集团收入贡献。

若客户本来准备买另一只 Chanel，随后改买新包，证据支持品牌内部选择变化。若只是更常使用新包，证据支持使用场景分工；购买支出变化仍待问。日常用途也可能伴随未购买或退货，须保留这些结果。

广告接触发生在购买前，是效果研究需要的时间条件。要进一步归因，还需能够比较接触与未接触人群，并处理上新、供货、价格与客户差异。访谈可帮助找到这些条件，不能独立完成营销效果估计。

现有公开记录的试填见 [证据适配表](customer_choice_instrument_fit.csv)。其中多数缺少品牌备选和预算回答，当前统一保留 `unknown`。下一轮若有可访问受访者，先试访并检查问题是否被理解、预算与日期是否能被回忆，再修订措辞和开展取样。

[空白记录模板](customer_choice_interview_template.csv)采用每行一次选择经历；通过 `linked_event_id` 连接退换与再次购买。字段较多时可先按问答记笔记，再补结构化记录。当前未联系论坛发言者，也未创建新采访结果。
